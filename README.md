# Integrative Project

A software engineering project demonstrating the design and implementation of a small web-based system with authentication-related utilities and supporting system models.

## Overview

This repository contains project artefacts including:

- PHP utilities for OTP and QR-code generation
- HTML used for project-related interfaces
- Entity Relationship, class, and use-case diagrams
- A packaged project archive

The diagrams document the system design, while the PHP/HTML files contain implementation components.

## Tech Stack

- PHP
- HTML
- QR-code generation library
- Draw.io diagrams

## Repository Structure

| File | Purpose |
| --- | --- |
| `otp-generator.php` | Generates one-time passwords for the system |
| `qr-code-generator.php` | Generates QR codes |
| `install-qrcode-library.php` | Sets up the QR-code dependency |
| `generators.html` | HTML interface for generator functionality |
| `class diagram.drawio.png` | Class design diagram |
| `erd.drawio.png` | Database/entity relationship diagram |
| `usecase.drawio.png` | Use-case diagram |
| `ems.zip` | Packaged project files |

## Design Documentation

The included diagrams provide a high-level view of the system architecture, database relationships, and user interactions.

## Notes

This repository was created as part of university software engineering/integrative coursework. Some files are supporting project artefacts rather than standalone applications.
